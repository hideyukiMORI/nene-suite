# Documentation Policy Self-Review

Use for governance-only PRs (ADR, workflow, AGENTS, milestones) without code.

## Checklist

- [ ] Issue linked; English for public repo docs.
- [ ] ADR status and context/consequences complete when adding ADRs.
- [ ] `AGENTS.md` and `.cursor/rules/` updated if entry points change.
- [ ] `docs/todo/current.md` reflects done/next when work state changes.
- [ ] Internal links resolve; sibling links use GitHub URLs not broken relative paths.
- [ ] No contradiction with binding docs (`scope-contract`, `orchestration-compliance`, `terminology`).
